# Findely

Findely is a private lead generation and lead intelligence platform.

The project helps users search for businesses, organize leads, evaluate opportunities and manage prospecting data from one interface.

## Overview

Findely is designed as a multi-user SaaS application with:

- User authentication
- Business and lead search
- Lead scoring and filtering
- Lead lists and saved prospects
- Usage quotas
- CSV exports
- Multi-language support
- Multiple data-source architecture

The project is currently in private development and is not intended for public deployment or redistribution.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Google Places API

## Architecture

The application includes:

- Server-side authentication
- PostgreSQL database persistence
- Row-Level Security
- Protected user routes
- Search and data-processing pipelines
- Deduplication and lead scoring
- Provider-based data sources
- Quota management

## Project status

Findely is currently under active development.

Some features are still being improved, including:

- Additional lead sources
- Public API access
- Advanced enrichment
- Payment integration
- Production monitoring
